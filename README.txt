------------------------------------------------------------
第一步：双击 start.bat
------------------------------------------------------------
自动帮你做：
  1) 没有内核就自动下载 mihomo（多源+浏览器兜底）
  2) 用 Python 脚本 build_live.py 自动从 4 个公共免费节点源抓最新节点
     （每次都现拉，因为免费节点寿命短）
  3) 自动剔除中国大陆节点(含广东)、保留港澳臺；再并发 TCP 实测只留活节点；
     按延迟排序只保留最快的 60 个（电脑端 config.yaml 与手机端 sub.yaml 同源生成）
  4) 生成 config.yaml（电脑用）+ sub.yaml（手机订阅用），注入本地控制端口
  5) 启动代理，并把 Windows 系统代理设好（浏览器/软件自动走代理）
  6) 弹出换节点面板；同时启动手机订阅服务（见下方"手机端"）

注意：第 3 步的实测需要你的电脑能直连节点 IP（普通家庭网络即可），
耗时约 30~60 秒。在隔离沙箱里测不通会退化为"保留全部非大陆节点"。

跑完显示"已开启"，并自动打开控制面板。

手机端 mihomo / Clash 配置（新订阅 URL）
============================================================
已为你准备好手机订阅服务。在【与电脑同一 WiFi】下：
  1) 电脑上双击 sub_server.bat —— 弹出管理员授权窗口时点"是"
     （这一步是放行防火墙 9099 端口，必须点，否则手机会报 EOF/连接失败）
  2) 之后保持那个黑色窗口开着（显示 Sub server started 就是正常）
  3) 手机 mihomo / Clash 里"添加订阅"，填（手机必须和电脑连同一个路由器/WiFi）：
         http://HP-ABC:9099/sub.yaml
     ★ 若你家有多个路由器/多个网段（如电脑同时在 192.168.3.x 和 192.168.101.x），
       手机和电脑必须连【同一个】WiFi，且地址用电脑在该网段的实际 IP。
       sub_server 启动时会自动打印当前所有局域网地址，照着填最准。
  4) 更新订阅即可。手机和电脑共用同一批免费节点。

★ 备用方案（订阅怎么都拉不到时用）：
  把桌面的 sub.yaml 用微信/QQ 发到手机，手机 mihomo 里点"浏览文件"
  直接导入这个文件，效果完全一样，连电脑服务都不用开。

★ 手机上若还报错：
  - 报 EOF / 连接失败 → 电脑的 sub_server.bat 没以管理员运行（防火墙没放行）
  - 报 超时 timeout  → 手机和电脑不在同一个 WiFi，或电脑 IP 变了
    （电脑 IP 查看：手机订阅地址里的数字要和电脑 ipconfig 里的 IPv4 一致）

常见问题
============================================================
Q：你（AI）帮我实际测过能不能开谷歌吗？
A：我在自己的运行环境里实跑验证了：mihomo 内核能正常启动、配置完全
   合法（正确监听了代理端口 7890 和控制端口 9090）。但我的运行环境
   网络被隔离，连不上那些节点服务器（日志显示节点 IP 直连超时），所以
   无法在我这边真正打开谷歌——这是环境限制，不是配置问题。你本机没有
   这层隔离，双击 start.bat + test-google.bat 就能真正连接节点开谷歌。
   若 test-google 不通，多半是免费节点临时失效，重跑 start.bat（会重新
   拉最新节点）或在 dashboard.url 里换节点即可。

Q：start.bat 提示节点源都连不上？
A：你当前 WiFi 可能也屏蔽了这些站。解决：用手机流量开热点，或复制一个
   Clash 订阅链接粘贴进 sub_url.txt（一行一个），重跑 start.bat。
   若仍不行，会用本文件夹内置的离线备份节点（config.backup.yaml）应急。

Q：免费节点能一直用吗？
A：不能，寿命几小时到几天。但每次启动现拉 + 每2小时自动维护，基本够用。
   明天开会前，请提前半小时跑一次 start.bat + test-google.bat 确认能开。

Q：家里有多个路由器/多个网段（如 192.168.3.x 和 192.168.101.x）怎么办？
A：免费代理只监听本机 127.0.0.1，内网直连不受影响。手机订阅要能连上，关键是
   手机和电脑必须在【同一个 WiFi/网段】。两个路由器是两个子网，跨子网默认互不可达。
   最稳的做法：把副路由器（aijiujiu2lou）改成 AP/桥接模式，让它和主路由共用一个网段，
   这样无论连哪个 WiFi 都是同一个 192.168.3.x，地址永远不变。临时方案：手机和电脑连同一个
   WiFi，并按 sub_server 启动时打印的当前地址填订阅 URL。
