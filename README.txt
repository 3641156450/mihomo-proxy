============================================================
  网络工具包 使用说明
  适合：只想点一下就能用的用户
============================================================

文件夹位置：<项目文件夹>
里面已配好"客户端 + 自动获取节点 + 手机订阅 + 自动维护"。

【节点源】每次启动现拉最新公共节点，解析后做三件事：
  ① 剔除不需要的地区节点；
  ② 并发实测，只把"活着的"节点留下来；
  ③ 按连接延迟排序，只保留最快的一批。
电脑端与手机端配置由同一份活节点生成，两端同步。

------------------------------------------------------------
第一步：双击 start.bat
------------------------------------------------------------
自动帮你做：
  1) 没有内核就自动下载；
  2) 用脚本自动从公共节点源抓最新节点（每次都现拉，因为节点寿命短）；
  3) 剔除不需要地区、实测只留活节点、按延迟排序；
  4) 生成配置文件（电脑用）+ 手机订阅用配置，注入本地控制端口；
  5) 启动，并把 Windows 系统代理设好；
  6) 弹出换节点面板；同时启动手机订阅服务。

注意：实测需要电脑能直连节点，耗时约 30~60 秒。

跑完显示"已开启"，并自动打开控制面板。

------------------------------------------------------------
第二步：双击 test-google.bat
------------------------------------------------------------
直接告诉你目标网站能不能打开。能打开 = 成功。

------------------------------------------------------------
第三步（可选）：换节点 / 切模式
------------------------------------------------------------
双击 dashboard.url 打开网页控制面板（主机 127.0.0.1:9090）。
  左上角选代理组可手动挑节点；想省事保持自动（自动选最快）。
  某些网站打不开，把右上角模式切到"全局(Global)"。

------------------------------------------------------------
不用了就双击 stop.bat（关代理 + 清系统代理 + 关订阅服务）
------------------------------------------------------------

------------------------------------------------------------
手机端配置（新订阅 URL）
============================================================
已为你准备好手机订阅服务。在【与电脑同一 WiFi】下：
  1) 电脑上双击 sub_server.bat —— 弹出管理员授权窗口时点"是"
     （这一步是放行防火墙端口，必须点，否则手机会报 EOF/连接失败）
  2) 之后保持那个黑色窗口开着；
  3) 手机客户端里"添加订阅"，填（手机必须和电脑连同一个路由器/WiFi）：
         http://<你的电脑主机名>:9099/sub.yaml
     若家中有多个路由器/多个网段，手机和电脑必须连【同一个】WiFi，
     且地址用电脑在该网段的实际 IP。sub_server 启动时会自动打印当前
     所有局域网地址，照着填最准。
  4) 更新订阅即可。手机和电脑共用同一批节点。

★ 备用方案（订阅怎么都拉不到时用）：
  把桌面的 sub.yaml 用微信/QQ 发到手机，手机客户端里点"浏览文件"
  直接导入这个文件，效果完全一样，连电脑服务都不用开。

★ 手机上若还报错：
  - 报 EOF / 连接失败 → 电脑的 sub_server.bat 没以管理员运行（防火墙没放行）
  - 报 超时 timeout  → 手机和电脑不在同一个 WiFi，或电脑 IP 变了
    （电脑 IP 查看：手机订阅地址里的数字要和电脑 ipconfig 里的 IPv4 一致）

============================================================
自动维护
============================================================
已创建自动化任务，每 2 小时自动：
  重新抓最新节点 -> 剔除不需要地区 -> 实测只留活节点
  -> 重建配置 -> 校验配置 -> 必要时重启内核。
所以节点过期也不怕，电脑开着就会自动续上。

============================================================
常见问题
============================================================
Q：你（AI）帮我实际测过能不能开目标网站吗？
A：我在自己的运行环境里实跑验证了：内核能正常启动、配置完全
   合法（正确监听了代理端口和控制端口）。但我的运行环境
   网络被隔离，连不上那些节点服务器，所以无法在我这边真正打开——
   这是环境限制，不是配置问题。你本机没有这层隔离，双击即可真正连接。
   若测试不通，多半是节点临时失效，重跑 start.bat 即可。

Q：start.bat 提示节点源都连不上？
A：你当前 WiFi 可能也屏蔽了这些站。解决：用手机流量开热点，或复制一个
   订阅链接粘贴进 sub_url.txt（一行一个），重跑 start.bat。

Q：节点能一直用吗？
A：不能，寿命几小时到几天。但每次启动现拉 + 每2小时自动维护，基本够用。

Q：家里有多个路由器/多个网段怎么办？
A：代理只监听本机 127.0.0.1，内网直连不受影响。手机订阅要能连上，关键是
   手机和电脑必须在【同一个 WiFi/网段】。两个路由器是两个子网，跨子网默认互不可达。
   最稳的做法：把副路由器改成 AP/桥接模式，让它和主路由共用一个网段，
   这样无论连哪个 WiFi 都是同一个网段，地址永远不变。临时方案：手机和电脑连同一个
   WiFi，并按 sub_server 启动时打印的当前地址填订阅 URL。
