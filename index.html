包里有什么

  • mihomo.exe —— 代理内核（Clash.Meta 分支）
  • build_live.py —— 从 18 个公共源抓取、测速、去重生成节点配置
  • sub_server.py / sub_server.bat —— 本地订阅中转服务（0.0.0.0:9099）
  • start.bat / stop.bat —— 一键启动 / 停止
  • set_proxy.py —— 设置 Windows 系统代理
  • keepalive_sub.py —— 订阅保活（配合系统计划任务每 5 分钟）
  • config.yaml / sub.yaml / README.txt / AUTOMATION_TASK.md

怎么用

  1. 下载并解压到任意目录（例如 D:\mihomo-proxy）。
  2. 右键 start.bat 以管理员身份运行，启动内核与订阅服务。
  3. 本机客户端订阅地址：http://127.0.0.1:9099/sub.yaml。
  4. 手机等其他设备：连同一 Wi-Fi，用电脑主机名访问 http://HP-ABC:9099/sub.yaml（或把 HP-ABC 换成电脑的局域网 IP）。
  5. 设置系统代理后即可上网；不用时运行 stop.bat。
双路由器 / 双 IP 注意：若你家有两个路由器（如 aijiujiu 的 192.168.3.x 与 aijiujiu2lou 的 192.168.101.x）， 手机若连的是另一网段，需把订阅地址里的主机名换成电脑当前所在网段的 IP，或把副路由改成 AP / 桥接模式，让全家在一个网段下。 订阅服务已绑定 0.0.0.0 并会在启动时打印所有局域网 IP，照着填即可。
